# CS50P Problem Set Solutions

Personal solutions to Harvard's [CS50's Introduction to Programming with Python (CS50P)](https://cs50.harvard.edu/python/), completed in CS50.dev.

## Problem sets

Solutions are grouped by problem set. Each folder contains the relevant problem directories and, where needed, supporting files.

- Problem set 0 — Functions
- Problem set 1 — Conditionals
- Problem set 2 — Loops
- Problem set 3 — Exceptions
- Problem set 4 — Libraries
- Problem set 5 — Unit Tests
- Problem set 6 — File I/O
- Problem set 7 — Regular Expressions
- Problem set 8 — Object-Oriented Programming

See the [official problem set instructions](https://cs50.harvard.edu/python/psets/) for the prompts and requirements.

## How to use this repository

These are personal solutions for study and comparison, not official CS50 solutions. Try each problem on your own before looking at the code. Use the solutions to understand different approaches, and follow CS50's academic honesty rules. Do not submit copied code as your own.
